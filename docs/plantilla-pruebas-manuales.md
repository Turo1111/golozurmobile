## 7. Instrucciones de uso

1. Duplicá esta plantilla para cada ejecución o ambiente si hace falta.
2. Completá primero contexto, alcance y referencias.
3. Definí los escenarios a validar.
4. En cada escenario documentá:
   - qué hiciste
   - qué esperabas
   - qué pasó realmente
   - evidencia disponible
5. Marcá el estado con checkbox.
6. Usá solo uno de estos estados por escenario:
   - `PASS`
   - `FAIL`
   - `N/A`
7. Si algo falla, describilo con precisión. Nada de notas vagas.
8. Las secciones de defectos/observaciones y cierre final son opcionales para corridas rápidas.

## 8. Criterios de aprobación

- cada escenario tiene estado explícito
- cada `FAIL` explica el síntoma concreto
- hay evidencia o notas útiles para reproducir
- si se completa el cierre final, resume qué quedó aprobado y qué no
